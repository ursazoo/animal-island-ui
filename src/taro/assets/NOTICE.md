# Icon attribution

CloseIcon, ChevronDownIcon, CheckIcon and DonutIcon from naive-icons 1.6.0.
They are generated by scripts/generate-taro-icons.mjs. Source license: MIT.
Original upstream package and its LICENSE remain available via the package's naive-icons dependency.

The full icon MIT license is copied into dist/taro/ICON-LICENSE.txt during the library build.
